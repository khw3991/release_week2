숫자 야구 게임(Bulls and Cows)
: 랜덤으로 생성된 중복 없는 4자리 숫자를 맞추는 게임입니다.

-S(strike) : 숫자와 위치가 모두 일치한 추측의 개수를 의미합니다.
-B(ball) : 정답 숫자에 포함되나 그 위치가 다른 추측의 개수를 의미합니다.
-O(out) : 정답 숫자에 포함되지 않는 숫자의 개수를 의미합니다.

-키보드 입력 또는 화면의 키패드를 통해 추측 숫자를 입력할 수 있습니다.
-제한된 10번의 기회 안에 정답 숫자를 맞혀야 합니다.
-정답의 각 자릿수는 모두 다른 숫자이며, 추측 입력에도 중복되는 숫자를 입력할 수 없습니다.
